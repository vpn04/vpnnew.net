## 五、已经购买灯塔Cloud的用户怎么办？

### 1. 立即停止续费与充值

不要因为“续费后才能恢复账号”“充值后可以迁移套餐”等未经验证的说法再次付款。即使部分旧节点仍能连接，也不代表后台、售后和长期服务已经恢复。

### 2. 保存完整证据

建议保存：

- 用户账号和套餐页面截图；
- 订单编号、支付时间和金额；
- 支付宝、微信、银行卡或其他付款凭证；
- 工单、邮件、Telegram等客服沟通记录；
- 官方公告、群组状态和域名异常截图；
- 节点、订阅更新失败和客户端报错截图。

不要为了截图而公开完整订阅链接，订阅地址可能包含账号权限。

### 3. 尝试原支付渠道申诉

能否退款取决于支付方式、交易时间和平台规则。申诉时应如实描述“购买的网络服务无法使用、官网和客服无法联系”等情况，并提交真实凭证。

警惕任何声称“先交手续费、保证金或验证金才能退款”的陌生账号，避免二次损失。

### 4. 尽快迁移重要业务

如果灯塔Cloud仍有个别节点可用，也不要继续把重要工作完全依赖在上面。优先迁移：

- 远程办公和会议；
- AI工具和海外账号登录；
- 跨境电商或社交媒体运营；
- 家庭多设备和路由器配置；
- 需要固定时间稳定访问的任务。

### 5. 检查账号安全

如果灯塔Cloud密码与邮箱、社交账号或其他网站重复使用，应立即更换相关密码，并开启可用的双重验证。不要在来历不明的“新灯塔官网”输入旧账号和支付信息。

## 六、如何识别假的灯塔Cloud新官网？

服务失联后，搜索结果、群聊和私信里可能出现自称“新官网”“接管团队”或“退款客服”的地址。

在没有原官方渠道交叉确认前，不要仅凭相同Logo或品牌名相信新网站。至少检查：

1. 原官方频道是否同步发布相同地址；
2. 旧账号和订单能否直接恢复，而不是要求重新付费；
3. 是否解释失联原因并给出可核验的补偿方案；
4. 客服是否要求提供密码、完整订阅链接或验证码；
5. 收款主体是否突然改变且拒绝说明。

仅仅“网页能打开”或“界面和以前一样”，不足以证明运营主体相同。

灯塔Cloud至少需要同时满足以下条件，才适合重新评估：

- 原官方渠道发布可验证的恢复公告；
- 主域名或可信备用域名持续稳定访问；
- 原用户账号、套餐和订单数据正常；
- 订阅更新和主要节点连续多日稳定；
- 客服恢复响应并处理存量工单；
- 对失联原因、服务补偿和后续运营给出明确说明。

只恢复一个网页、少数节点短暂上线或出现未经验证的新客服，都不足以解除预警。

### 灯塔Cloud机场跑路了吗？

### 灯塔Cloud官网打不开怎么办？

可以先用不同运营商网络排除单一本地网络故障，但不要继续充值，也不要相信未经旧官方渠道验证的新域名。应保存订单、支付记录、套餐截图、工单和聊天记录，并尽快迁移重要业务。

### 灯塔Cloud恢复后可以继续使用吗？

应等待原官方渠道恢复、节点和订阅连续稳定、客服重新响应，并对失联原因及补偿方案给出可验证说明。仅出现一个新网址或短暂恢复访问，不足以解除风险预警。
