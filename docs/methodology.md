# YouYou 评测方法与评分标准

VPN 和机场服务会受到地区、运营商、时间段、协议、客户端和节点负载影响。本站的评测不会把一次测速当成永久结论，而是更看重长期可用性、晚高峰稳定性和订阅风险。

## 核心评测维度

| 维度 | 观察重点 | 权重 |
| --- | --- | --- |
| 稳定性 | 是否频繁断连、节点是否大面积失效、订阅是否长期可用 | 高 |
| 晚高峰速度 | 20:00-24:00 的 YouTube、网页、下载和延迟表现 | 高 |
| 流媒体解锁 | Netflix、YouTube、Disney+、TikTok 等平台可用性 | 中 |
| AI 工具访问 | ChatGPT、Claude、Gemini 等服务是否容易触发风控 | 中 |
| 价格与套餐 | 单价、流量、倍率、退款/试用政策、是否有隐藏限制 | 中 |
| 客户端兼容 | Clash、Shadowrocket、Sing-box、官方客户端导入体验 | 中 |
| 售后响应 | 工单、群组通知、故障处理速度、公告透明度 | 中 |
| 风险信号 | 官网异常、客服失联、节点长期不可用、群组关闭、数据丢失 | 高 |

## 测试流程

1. 记录套餐价格、流量、倍率、可用协议和主要入口。
2. 导入订阅到常见客户端，检查 Clash、Shadowrocket、Sing-box 等兼容性。
3. 分别观察日间和晚高峰连接体验，避免只用低峰期数据下结论。
4. 测试网页访问、视频播放、AI 工具访问和常见流媒体解锁。
5. 结合用户反馈、公告记录、历史稳定性和跑路风险信号给出建议。

## 评分解释

本站更重视“普通用户长期能不能稳定使用”，不是只追求单次测速最高值。

- 推荐：长期表现稳定，价格、售后和风险控制比较均衡。
- 可试用：有亮点，但需要先小额测试，避免长期大额订阅。
- 谨慎：存在明显不稳定、售后弱、信息不透明或风险信号。
- 不建议：已经出现严重故障、跑路预警、客服失联或用户损失反馈。

## 重要说明

所有评测都具有时间性。机场和 VPN 服务可能随时调整线路、价格、入口、协议和解锁能力。阅读评测时，请同时关注文章里的发布时间、最近更新时间和页面评论区反馈。
