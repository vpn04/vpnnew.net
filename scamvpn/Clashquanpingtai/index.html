🧠 Clash 是什么？

Clash 是一个基于规则的代理工具，支持：

  • Shadowsocks
  • V2Ray
  • Trojan

它的核心优势在于：

✅ 智能分流（国内直连 / 国外代理）
✅ 多节点切换
✅ 支持订阅自动更新
✅ 支持 TUN 全局代理

相比传统 VPN，Clash 更像一个 “网络流量调度器”。

⚙️ Clash 工作原理

Clash 通过以下方式实现代理：

  1. 捕获网络请求
  2. 根据规则判断是否走代理
  3. 选择最优节点转发

例如：

  • 国内网站 → 直连
  • Google / YouTube → 代理

👉 这就是 规则分流（Rule-based Proxy）

🧩 Clash 基础使用流程

所有平台使用逻辑基本一致：

第一步：获取订阅链接

由机场提供（核心）

第二步：导入订阅

在客户端中粘贴订阅地址

第三步：更新节点

刷新配置获取服务器列表

第四步：选择节点

选择延迟低、稳定的节点

第五步：开启代理

开启系统代理或 TUN 模式

💻 Windows 使用教程（Clash for Windows）

📥 安装

下载 Clash for Windows 并安装。

⚙️ 配置步骤

  1. 打开软件
  2. 进入 Profiles
  3. 粘贴订阅链接
  4. 点击 Download
  5. 切换到 Proxies 选择节点

🌐 开启代理

  • 打开 System Proxy
  • 或开启 TUN Mode（推荐）

👉 新手建议先用系统代理

📲 iOS 使用教程（Shadowrocket / 小火箭）

由于 iOS 限制，Clash 不直接支持，需要使用：

  • Shadowrocket
  • Stash

配置步骤：

  1. 打开 Shadowrocket
  2. 点击订阅
  3. 添加订阅链接
  4. 更新节点
  5. 开启连接

特点：

  • 简单易用
  • 支持全局代理

⚡ TUN 模式 vs 系统代理

🔹 系统代理模式

特点：

  • 仅代理浏览器等应用
  • 配置简单
  • 兼容性高

缺点：

  • 无法代理游戏
  • 无法代理系统流量

🔹 TUN 模式（推荐）

特点：

  • 全局代理
  • 支持 TCP + UDP
  • 游戏可用

缺点：

  • 需要管理员权限
  • 配置稍复杂

🆚 对比总结

功能系统代理TUN模式
覆盖范围部分应用全局
游戏支持❌✅
配置难度简单较复杂
推荐人群新手进阶用户

👉 建议：熟练后使用 TUN

❗ 常见问题 FAQ

Clash 怎么用？

导入订阅 → 选择节点 → 开启代理即可。

Clash 需要买吗？

Clash 本身免费，但节点需要付费。

Clash 为什么连不上？

常见原因：

  • 订阅失效
  • 节点异常
  • DNS问题

Clash 用系统代理还是TUN？

新手：系统代理
进阶：TUN模式

iOS 为什么没有 Clash？

因为系统限制，需要使用 Shadowrocket。
