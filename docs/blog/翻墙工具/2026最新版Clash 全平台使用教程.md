## 🧠 Clash 是什么？

Clash 是一个基于规则的代理工具，支持：

- Shadowsocks  
- V2Ray  
- Trojan  

它的核心优势在于：

✅ 智能分流（国内直连 / 国外代理）  
✅ 多节点切换  
✅ 支持订阅自动更新  
✅ 支持 TUN 全局代理  

相比传统 VPN，Clash 更像一个 **“网络流量调度器”**。

---

## ⚙️ Clash 工作原理

Clash 通过以下方式实现代理：

1. 捕获网络请求  
2. 根据规则判断是否走代理  
3. 选择最优节点转发  

例如：

- 国内网站 → 直连  
- Google / YouTube → 代理  

👉 这就是 **规则分流（Rule-based Proxy）**

## 💻 Windows 使用教程（Clash for Windows）

### 📥 安装

下载 Clash for Windows 并安装。

### ⚙️ 配置步骤

1. 打开软件  
2. 进入 Profiles  
3. 粘贴订阅链接  
4. 点击 Download  
5. 切换到 Proxies 选择节点  

### 🌐 开启代理

- 打开 **System Proxy**
- 或开启 **TUN Mode（推荐）**

👉 新手建议先用系统代理

## ⚡ TUN 模式 vs 系统代理

### 🔹 系统代理模式

特点：

- 仅代理浏览器等应用  
- 配置简单  
- 兼容性高  

缺点：

- 无法代理游戏  
- 无法代理系统流量  

---

### 🔹 TUN 模式（推荐）

特点：

- 全局代理  
- 支持 TCP + UDP  
- 游戏可用  

缺点：

- 需要管理员权限  
- 配置稍复杂  

---

### 🆚 对比总结

| 功能 | 系统代理 | TUN模式 |
|------|--------|--------|
| 覆盖范围 | 部分应用 | 全局 |
| 游戏支持 | ❌ | ✅ |
| 配置难度 | 简单 | 较复杂 |
| 推荐人群 | 新手 | 进阶用户 |

👉 建议：熟练后使用 TUN
