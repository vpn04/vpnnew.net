## 一、什么是 Shadowrocket

Shadowrocket（小火箭）是 iOS 平台上非常流行的代理工具，支持多种代理协议，例如：

* Shadowsocks
* V2Ray
* Trojan
* SOCKS5
* HTTP
* WireGuard（部分支持）

Shadowrocket 最大的特点是 **界面简单、配置方便、iPhone 使用体验好**，因此很多 iOS 用户都会选择 Shadowrocket。

**Shadowrocket 特点：**

* 仅支持 iOS
* 需要在 App Store 付费购买
* 支持订阅链接
* 支持规则分流
* 操作简单
* 稳定性好

---

## 二、什么是 Clash

Clash 是一个支持多平台的代理客户端，功能非常强大，支持规则分流、策略组、自动测速、负载均衡等高级功能。

Clash 有多个版本：

* Clash for Windows
* Clash for Mac
* Clash for Android
* Clash Verge
* Clash Meta
* Clash X

Clash 更适合进阶用户和电脑用户。

**Clash 特点：**

* 支持 Windows / Mac / Android
* 规则分流非常强大
* 支持策略组
* 支持自动测速
* 支持 TUN 模式
* 可自定义配置 YAML

---

## 三、Shadowrocket vs Clash 核心区别

| 对比项目   | Shadowrocket   | Clash                   |
| ------ | -------------- | ----------------------- |
| 支持系统   | iOS            | Windows / Mac / Android |
| 是否开源   | 否              | 是                       |
| 配置方式   | 简单             | 较复杂                     |
| 规则分流   | 支持             | 非常强大                    |
| 策略组    | 不支持            | 支持                      |
| 自动测速   | 不支持            | 支持                      |

| 上手难度   | 简单             | 中等                      |
| 自定义能力  | 一般             | 很强                      |

**总结一句：**

* iPhone 用 Shadowrocket
* Windows / Mac / Android 用 Clash

## 四、速度和稳定性对比

很多人关心 Shadowrocket 和 Clash 哪个更快，其实：

**速度主要取决于：**

* 节点质量
* 协议（WireGuard / Trojan / V2Ray）
* 网络环境
* 是否使用 UDP
* 是否使用 TUN 模式

不是客户端决定速度，而是 **协议和节点** 决定速度。

不过在实际使用中：

| 场景      | Shadowrocket | Clash |
| ------- | ------------ | ----- |
| iPhone  | 很稳定          | 一般    |
| Windows | 不支持          | 非常稳定  |
| Mac     | 一般           | 稳定    |
| Android | 不支持          | 稳定    |
| 游戏加速    | 一般           | 更好    |
| 全局代理    | 稳定           | 稳定    |
| 分流规则    | 一般           | 非常强   |

**结论：**

* 手机 iPhone → Shadowrocket 更好
* 电脑 → Clash 更好
* 游戏 / 分流 → Clash 更好

## 八、FAQ 常见问题

### 1. Shadowrocket 和 Clash 哪个更快？

速度主要取决于节点和协议，不取决于客户端，但 Clash 在电脑和游戏场景下表现更好。

### 2. iPhone 可以用 Clash 吗？

可以使用 Clash iOS（TestFlight），但稳定性和体验不如 Shadowrocket。

### 3. Clash 和 Shadowrocket 可以同时用吗？

可以，不同设备使用不同客户端即可。

### 4. 新手应该用哪个？

新手建议使用 Shadowrocket，电脑用户建议使用 Clash。

### 5. Clash 为什么这么多人用？

因为 Clash 支持规则分流、策略组、自动测速、TUN 模式，非常强大。

如果你是 iPhone 用户，Shadowrocket 是最适合你的代理工具；如果你使用 Windows、Mac 或 Android，那么 Clash 是功能更强大、更灵活的选择。

* iPhone → Shadowrocket

* 新手 → Shadowrocket
