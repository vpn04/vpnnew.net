## 🧮核心注册流程详解

### 📜第一步：启动应用并输入号码
1. 打开Telegram应用。
2. 点击 "**Start Messaging**" (开始聊天)。
3. 输入您的手机号码，**务必包含国家区号** (例如中国为 **+86**)。

### 📄第二步：解决验证码接收问题 (关键步骤)
这是国内用户最常见的难题，若收不到验证码，请按以下顺序排查：

| 📕问题原因 | 📖解决方案 |
| :--- | :--- |
| **运营商拦截** | 优先使用**移动、联通、电信**的主流号段，避免虚拟运营商。 |
| **格式错误** | 检查号码格式是否为 **+86 [您的手机号]**。 |
| **短信被拦截** | 检查手机的“骚扰拦截”或“垃圾短信”文件夹。 |
| **系统风控** | 避免短时间内多次请求，等待**15-30分钟**后再试。 |

### 📗第三步：完成账户设置
- 验证成功后，设置您的**显示名称** (建议使用英文或拼音便于国际客户识别)。
- **上传头像** (使用真实照片可增加信任度)。
- **强烈建议**：在 `设置 -> 隐私与安全` 中开启**两步验证**，为账号增加额外安全保障。

## 📝界面语言设置为中文

刚注册的Telegram通常是英文界面，可通过以下任一方法切换为中文：

- **🖋️方法一 (最快)**：
  1. 在应用中点击此链接：[**中文化链接**](https://t.me/setlanguage/classic-zh) (需在App内点击)。
  2. 点击 "**Apply Localization**" (应用本地化)。

- **🖊️方法二 (手动)**：
  1. 进入 `Settings` (设置) -> `Language` (语言)。
  2. 选择 `简体中文 (Chinese Simplified)`。
