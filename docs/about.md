# 关于 YouYou

YouYou 是一个长期更新的 VPN 推荐、机场评测、Clash / Shadowrocket 教程与科学上网问题排查站点。

本站主要服务三类用户：第一次接触 VPN 或代理工具的新手、需要稳定访问海外服务的长期用户，以及希望在订阅机场前先做风险判断的人。

## 我们做什么

- 整理 VPN、机场、Clash、Shadowrocket、Telegram、AI 工具访问等实用教程。
- 跟踪机场套餐、节点可用性、晚高峰表现、流媒体解锁和跑路风险。
- 汇总免费试用、优惠信息、常见故障、订阅避坑和跑路预警。
- 用尽量清楚的步骤，把复杂配置拆成普通用户可以照着排查的流程。

## 内容原则

本站的内容会尽量保持四个标准：

- 可复查：重要结论尽量说明测试维度、更新时间和判断依据。
- 可理解：教程优先使用新手能看懂的语言，不故意制造技术门槛。
- 可更新：VPN 和机场服务变化很快，过期信息会持续修订。
- 可纠错：如果你发现链接失效、价格变化、描述错误或测试结果过期，可以通过联系页反馈。
